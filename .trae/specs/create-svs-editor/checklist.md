# Checklist

## UI 布局
- [ ] 主窗口为左右分栏布局（左侧轨道面板 200px，右侧钢琴卷帘自适应）
- [ ] 顶部工具栏包含播放/暂停/停止按钮、时间显示、BPM 输入、拍号输入
- [ ] 窗口标题显示 "SXSEditor"

## 钢琴卷帘
- [ ] Canvas 正确绘制钢琴键背景（黑键/白键）
- [ ] Canvas 正确绘制网格线（小节线、拍线）
- [ ] 音符块按轨道颜色绘制，显示歌词文本
- [ ] 鼠标点击空白处可创建音符
- [ ] 鼠标拖拽音符可移动位置
- [ ] 拖拽音符边缘可调整时长
- [ ] 按 Delete 键可删除选中音符
- [ ] 双击音符可编辑歌词

## 轨道管理
- [ ] 左侧显示轨道列表，包含轨道名、歌手名、颜色块
- [ ] 点击 "+" 按钮可添加新轨道
- [ ] 可选择每条轨道使用的歌手/模型
- [ ] 删除轨道功能可用

## 播放控制
- [ ] 播放按钮可启动音频播放
- [ ] 暂停/停止按钮功能正常
- [ ] 播放头随播放进度移动
- [ ] BPM 和拍号设置影响网格和播放速度

## SVS 推理
- [ ] 正确加载所有 ONNX 模型（note_text_encoder, note_pitch_encoder, note_type_encoder, f0_encoder, preflow, cond_emb, diff_step, vocoder）
- [ ] 音符序列正确转换为模型输入张量
- [ ] 推理管线按顺序执行并输出梅尔频谱
- [ ] 声码器将梅尔频谱转换为音频波形
- [ ] GPU 后端优先启用，推理速度合理

## 音频导出
- [ ] 导出按钮弹出保存对话框
- [ ] 合成音频保存为 WAV 格式（24kHz, 32-bit float）
- [ ] 导出文件可正常播放

## 工程文件
- [ ] 保存工程生成 JSON 文件，包含所有音符和轨道信息
- [ ] 加载工程文件可恢复编辑状态
- [ ] JSON Schema 包含版本号以便后续兼容
