## svssinger数据结构

### 歌手文件夹结构
```
svssinger/
└── {singer_name}/
    ├── avatar.png          # 头像图片
    ├── audio.wav           # 参考音频（44100Hz，单声道）
    └── singer_data.json    # 歌手数据（包含所有信息）
```

### singer_data.json 结构
```json
{
  "index": "vocal_320_10687",
  "language": "Mandarin",
  "time": [320, 10687],
  "duration": "0.23 0.34 0.26 0.70 0.52 0.46 0.36 0.44 0.14 0.24 0.64 0.47 0.51 1.10 0.28 0.38 0.32 0.32 0.38 0.32 0.31 0.19 1.45",
  "text": "<SP> 除 了 想 你 你 <SP> 除 了 了 爱 你 你 <SP> 我 什 么 什 么 都 愿 愿 意",
  "phoneme": "<SP> zh_chu2 zh_le5 zh_xiang3 zh_ni3 zh_ni3 <SP> zh_chu2 zh_le5 zh_le5 zh_ai4 zh_ni3 zh_ni3 <SP> zh_wo3 zh_shen2 zh_me5 zh_shen2 zh_me5 zh_dou1 zh_yuan4 zh_yuan4 zh_yi4",
  "note_pitch": "0 62 65 67 67 69 0 67 69 65 67 69 67 67 66 64 64 60 60 65 67 0",
  "note_type": "1 2 2 2 2 3 1 2 2 3 2 2 3 1 2 2 2 2 2 2 2 3 2",
  "f0": "0.0 0.0 0.0 294.1 288.2 290.6 294.6 295.7 ..."
}
```

字段说明：
- **index**: 歌手唯一标识
- **language**: 语言（如Mandarin）
- **time**: [起始时间ms, 结束时间ms]
- **duration**: 空格分隔的字符串，每个音节/字的时长（秒）
- **text**: 空格分隔的字符串，歌词文本，`<SP>`表示静音/停顿
- **phoneme**: 空格分隔的字符串，音素序列，`<SP>`表示静音
- **note_pitch**: 空格分隔的字符串，MIDI音高值，0表示静音
- **note_type**: 空格分隔的字符串，音符类型（1=普通，2=连音，3=滑音等）
- **f0**: 空格分隔的字符串，F0基频值（Hz），0.0表示无声

### 步骤4: 创建audioPreprocess.js
核心功能：
1. **WAV波形渲染与交互**
   - 使用Canvas绘制波形
   - 与MIDI编辑器时间轴严格对齐
   - 点击波形可跳转播放位置

2. **播放控制**
   - Space键播放/暂停
   - 工具栏按钮播放/暂停
   - 播放头同步显示在波形和MIDI上

3. **F0和音高提取（预留接口）**
   - "自动获取F0和音高"按钮点击事件
   - 调用onnxrtnode模块（预留，暂时返回模拟数据）
   - RMVPE模型路径：`onnx_models/rmvpe.onnx`（待添加）
   - 音高模型：预留接口
   - 提取结果自动转换为singer_data.json格式

4. **数据保存**
   - F0数据暂存在内存中
   - 保存时将WAV、singer_data.json一起保存
   - 通过IPC调用主进程保存到svssinger目录
