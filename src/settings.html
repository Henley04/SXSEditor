编辑器中播放预览时使用的推理参数，可适当降低质量以换取更快的响应速度。

扩散模型的反向采样步数。步数越少推理越快，但音质下降；步数越多音质越好，但推理越慢。推荐预览使用 8~16 步。

无分类器引导强度。值越大贴合条件，但可能过度强化。设为 0 可跳过无条件预测。推荐 1.0~5.0。

CFG 结果的重缩放系数，用于缓解过度引导造成的伪影。推荐 0.5~0.9。

分块可显著加速长片段预览（片段越长加速越明显），代价是块边界处可能产生轻微伪影。短片段（短于分块大小）不会分块。

每个分块的目标帧数（1 帧 = 20ms 音频）。值越小加速越明显但边界伪影增多；值越大质量越好但加速减弱。推荐 300~800。

相邻分块间的重叠帧数，用 Hann 窗交叉淡入淡出消除拼接痕迹。值越大边界越平滑但计算量增加。推荐 30~100。设为 0 则不重叠（不推荐）。

导出 WAV 文件时使用的推理参数，默认使用更高质量的设置以获得最佳音质。

导出时的扩散步数。更多步数 = 更高质量。推荐导出使用 32 步。

导出时的 CFG 强度。导出时建议保持较高值以确保音质。

导出时的 CFG Rescale 系数。

长音频合成时，vocoder 按分片逐段推理再交叉淡入淡出拼接。分片越大显存占用越高、单次推理越慢；分片越小越省显存但拼接开销增加。

分片长度必须是 8 的倍数。值越大显存占用越高但拼接次数越少；值越小越省显存但拼接开销增加。默认 1008 帧（约 20 秒音频）。

ONNX Runtime 会话选项。这些参数在模型加载时生效，修改后会自动重置推理流水线。普通用户保持默认即可，高级用户可按需调优。

默认值说明
  • DML（DirectML GPU）路径下 enableMemPattern 默认关闭，防止 DirectML 过度预分配 GPU 内存池导致 OOM/TDR。
  • CPU/WASM 路径下 enableMemPattern 默认开启（ORT 官方推荐）。
  • NPU 静态形状模型强制使用 graphOptimizationLevel='basic'（已离线优化）。

分析计算图执行计划，让多个中间张量复用同一块内存，降低峰值显存并减少 malloc/free 开销。CPU 路径默认开启。DML 路径默认关闭（见下方"强制 DML 启用"）。

CPU 路径上的内存池分配器，复用已释放的内存块避免频繁分配。CPU 推理时建议开启；纯 GPU 推理时无影响。

图优化器级别。级别越高，加载时图变换越多（耗时增加），但运行时性能越好。NPU 静态形状模型固定为 basic（已离线优化）。

顺序模式按计算图顺序执行算子，延迟低；并行模式并行执行独立算子，吞吐量高但显存占用更大。单次推理建议顺序。

高级与高风险选项
⚠ 高风险警告
  • 以下选项在不合适的配置下可能导致推理失败、显存溢出或性能退化。
  • 仅在排查问题或性能调优时修改，并务必逐项测试。

在 DML（DirectML）执行提供者路径下启用 enableMemPattern。默认关闭。开启后 DirectML 可能过度预分配 GPU 内存池，触发 OOM 或 TDR 黑屏。仅在显存充裕且想测试 DML 内存复用收益时开启，并密切观察连续合成时的稳定性。

单个算子（如 MatMul）内部并行线程数，仅 CPU 路径有效。0=自动（由 ORT 按硬件决定）。设置过高可能引起线程竞争反而变慢；建议 ≤ 物理核心数。

独立算子之间的并行线程数，仅 CPU 路径且 executionMode=parallel 时有效。0=自动。多数模型按顺序执行收益不大，通常保持默认 0。

ORT native 日志级别。verbose 会打印每步推理的详细信息，严重影响性能（大量 IO）；仅用于排查问题。默认 warning。

独占模式绕过 Windows 音频混音器，可获得更低延迟和更高音质。

选择音频输出设备。独占模式下仅支持 WASAPI 设备。

输出采样率。独占模式下需设备支持所选采样率。

独占模式下的输出位深度。32-bit Float 提供最高精度动态范围。

较小的缓冲区降低延迟但增加 CPU 负载和爆音风险。

主输出音量控制。

WASAPI 独占模式说明
  • 独占模式直接访问音频硬件，绕过 Windows 音频混音器
  • 可实现位完美 (bit-perfect) 音频输出
  • 延迟可低至 1-3ms
  • 独占模式运行时，其他应用无法播放音频
  • 如设备不支持所选采样率/位深度，将自动回退到共享模式

选择音频转MIDI时使用的提取工具。

精度说明

选择声码器模型。SiFiGAN 需先在模型下载页下载。

SiFiGAN 单独选择精度。FP16 体积小、推理快，但音质下降明显 (余弦相似度约 0.95)；FP32 为全精度，音质最佳。默认 FP32。若所选精度的模型文件不存在，将自动回退到另一精度变体。

选择日语歌词的发声方式。英语音素迁移使用基础多语言模型，将日文假名映射为最接近的英语 ARPAbet 音素合成，无需额外下载；混合音素在英语音素迁移的基础上，对每个假名在英语 ARPAbet（音素级）与粤语 yue_（音节级）之间挑选发音最接近的一项——辅音优先粤语、纯元音优先粤语、ら行用粤 l 接近日语弹音 /ɾ/；拗音/浊行/汉字回退 ARPAbet；日语 LoRA 模型使用专门的日语微调模型，音质更佳但需单独下载（当前开发中，暂不可用）。

每次合成完成后重新加载 diffStep 和 vocoder，强制 DirectML 回收中间张量内存池，缓解连续合成 OOM。开启后会增加一点合成后的等待时间。

diffusion 完成后释放 diffStep session，让 vocoder 推理独占显存（腾出 ~3-4GB），避免 0x887A0006/TDR 黑屏。代价：每次 vocoder 后需重载 diffStep（~1-3秒），多段合成会变慢。SiFiGAN/低显存显卡强烈建议开启。
