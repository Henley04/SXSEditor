选择用于 DirectML 推理的 GPU 设备。自动模式优先选择独显，若无独显则选择显存最大的 GPU。

预览推理参数

编辑器中播放预览时使用的推理参数，可适当降低质量以换取更快的响应速度。

扩散模型的反向采样步数。步数越少推理越快，但音质下降；步数越多音质越好，但推理越慢。推荐预览使用 8~16 步。

无分类器引导 (Classifier-Free Guidance) 强度。值越大，生成结果越贴合条件（音高/歌词），但可能过度强化导致伪影。设为 0 可跳过无条件预测，推理速度约提升一倍。推荐范围 1.0~5.0。

CFG 结果的重缩放系数，用于缓解过度引导造成的伪影。0 = 完全使用 CFG 增强结果，1 = 完全使用原始预测。推荐 0.5~0.9。

导出推理参数

导出 WAV 文件时使用的推理参数，默认使用更高质量的设置以获得最佳音质。

导出时的扩散步数。更多步数 = 更高质量。推荐导出使用 32 步，如追求极致质量可尝试 48~64 步。

导出时的 CFG 强度。与预览参数说明相同，导出时建议保持较高值以确保音质。

导出时的 CFG Rescale 系数。与预览参数说明相同。

音频输出

独占模式绕过 Windows 音频混音器，可获得更低延迟和更高音质，但其他应用将无法同时使用音频设备。

选择音频输出设备。独占模式下仅支持 WASAPI 设备。

输出采样率。独占模式下需设备支持所选采样率，否则将回退到共享模式。

独占模式下的输出位深度。32-bit Float 提供最高精度动态范围。

较小的缓冲区降低延迟但增加 CPU 负载和爆音风险。独占模式下建议 256 以下。

主输出音量控制。独占模式下由软件控制音量，共享模式下由系统混音器控制。

WASAPI 独占模式说明
  • 独占模式直接访问音频硬件，绕过 Windows 音频混音器
  • 可实现位完美 (bit-perfect) 音频输出
  • 延迟可低至 1-3ms（取决于缓冲区大小）
  • 独占模式运行时，其他应用无法播放音频
  • 如果设备不支持所选采样率/位深度，将自动回退到共享模式
