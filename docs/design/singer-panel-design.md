# 歌手信息面板设计方案

## 概述
将歌手选择和歌手信息合并为一个面板，每个歌手包含完整的编辑功能。

## 数据结构

### 歌手 (Singer)
```javascript
{
  id: number,
  name: string,                    // 歌手名称
  color: string,                   // MIDI颜色（如 #3498db）
  volume: Envelope,                // 音量包络
  pan: Envelope,                   // 左右声道包络 (-1=左, 0=中, 1=右)
  modelPath: string,               // 模型路径（未来扩展）
}
```

### 包络 (Envelope)
```javascript
{
  keyframes: [
    { time: number, value: number, smoothness: number }, // time=拍, value=0-1或-1-1, smoothness=0-100
  ]
}
```

## UI布局

### 左侧面板 (280px)
```
┌─────────────────────────────────┐
│ 歌手列表 (+ 添加)                │
├─────────────────────────────────┤
│ [●] 主唱-1                   [×]│ ← 歌手标签（可点击选中）
│ [●] 主唱-2                   [×]│
├─────────────────────────────────┤
│ 歌手信息                         │
│ ┌─────────────────────────────┐ │
│ │ NM: [主唱-1          ]      │ │ NM = Name
│ │ CL: [#3498db] (颜色)         │ │ CL = Color
│ ├─────────────────────────────┤ │
│ │ VOL (音量)                   │ │
│ │ ┌─────────────────────────┐ │ │
│ │ │    ╭─╮     ╭───╮        │ │ │ ← 包络曲线
│ │ │ ───╯   ╰───╯             │ │ │
│ │ │ [0, 0.5] [2, 1] [4, 0.8]│ │ │
│ │ └─────────────────────────┘ │ │
│ ├─────────────────────────────┤ │
│ │ PAN (声像)                   │ │
│ │ ┌─────────────────────────┐ │ │
│ │ │ L─────────────R          │ │ │ ← 声像曲线 (-1 到 1)
│ │ │ [0, 0] [2, 0.5] [4, -0.3]│ │ │
│ │ └─────────────────────────┘ │ │
│ └─────────────────────────────┘ │
└─────────────────────────────────┘
```

## 缩写说明（鼠标悬停显示完整名称）
- **NM**: Name（名称）
- **CL**: Color（颜色）
- **VOL**: Volume（音量）
- **PAN**: Pan（声像/左右声道）
- **SM**: Smoothness（平滑程度）

## 关键帧交互
1. **左键点击空白处**: 添加关键帧（值=0.5，平滑=0）
2. **左键点击关键帧**: 选中关键帧
3. **左键拖拽关键帧**: 移动关键帧位置
4. **右键点击关键帧**: 弹出编辑菜单
   - Edit（编辑值和平滑）
   - Delete（删除）
5. **右键点击空白处**: 无操作

## 包络曲线渲染
- 水平方向：时间轴（拍）
- 垂直方向：
  - VOL: 0（底部）到 1（顶部）
  - PAN: -1（左）到 0（中）到 1（右）

## 缩进解释
使用首字母缩写节省空间，鼠标悬停时显示完整名称和数值范围。
