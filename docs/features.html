功能特性

探索 SXSEditor 的强大功能

🎹

多轨时间线编辑

在可视化多轨时间线上自由排列歌曲片段，支持拖拽调整位置和大小，像专业 DAW 一样管理你的项目。

🎼

钢琴卷帘编辑器

在钢琴卷帘视图中精确编辑音符、歌词和音高曲线。支持添加、删除、移动和调整音符长度。

🧠

神经网络歌声合成

使用 SoulX-Singer 声学模型，基于 ONNX Runtime 高效推理，将音符和歌词转化为自然真实的歌声。

🎤

歌手管理

创建和管理多个歌手，为每个歌手配置参考音频、头像、颜色标识和预处理 F0 数据。支持导出为 .sxssinger 文件。

📊

音频预处理

内置 RMVPE 和 Basic Pitch 音高检测器，自动从参考音频中提取 F0 与音符数据，为歌手创建提供完整支持。

▶️

实时播放与试听

直接在编辑器中合成并播放整个项目，支持暂停、停止和实时控制，即时感受创作效果。

📦

WAV 导出

将完成的混音项目导出为标准 WAV 文件，采样率 24000 Hz，可直接用于后续音频制作。

⚡

GPU 加速

通过 DirectML 支持 NVIDIA / AMD / Intel 独立显卡自动加速，大幅提升推理性能。同时支持 CPU 回退。

🖥️

跨平台桌面应用

基于 Electron 构建，原生级桌面体验。支持 Windows、macOS 和 Linux 三大平台打包分发。

📐

包络编辑器

精细编辑音高曲线、音量包络等参数，为每一个音符注入丰富的情感表达。

🔧

灵活的推理配置

在设置界面选择推理设备（自动选择或指定 GPU），灵活平衡性能与功耗。

🧪

完整的测试覆盖

160 余个自动化测试用例覆盖 WAV 编码、轨道管理、SVS 流水线、音高检测等核心功能模块。
