能做什么

从写第一个音符到导出完整的歌

SXSEditor 的核心流程很简单：写音符 → 填歌词 → 合成歌声 → 导出音频。 下面是每一步的具体能力。

🎹

像写 MIDI 一样写歌

在钢琴卷帘上点击放置音符，拖拽调整音高和时长。支持多轨编排，你可以同时写主旋律、和声，甚至给不同声部分配不同的歌手。

📝

每个音符都能填词

双击音符输入拼音或歌词，合成引擎会根据上下文自动处理发音。支持中文歌词，后续会扩展更多语言。

🎤

让虚拟歌手唱出来

基于 SoulX-Singer 声学模型，通过 ONNX Runtime 在本地运行。不需要联网，也不需要订阅——你的数据完全留在自己电脑上。

👤

创建自己的歌手

上传一段参考音频，程序会自动提取音高特征，创建一个专属的 .sxssinger 歌手文件。你可以为每个项目使用不同的声线。

📊

自动提取音高

内置 RMVPE 和 Basic Pitch，可以从任何音频中提取 F0 曲线和 MIDI 音符。想翻唱一首歌？先把原唱的音高抓下来作为参考。

▶️

边写边听

写完一段就能立刻合成试听，不满意再改。不用等整个项目做完，创作过程更流畅。

📦

导出 WAV

合成完成后导出为标准 WAV 文件（24kHz），可以直接导入到其他 DAW 里做后期混音，或者就这样直接发布。

⚡

显卡加速

有 NVIDIA、AMD 或 Intel 独显的话，合成速度会快很多。没有独显也能跑，就是慢一点，完全不影响使用。

🖥️

桌面应用

基于 Electron 构建，原生桌面体验。目前在 Windows 上测试最充分，macOS 和 Linux 理论上也能编译运行。

📐

微调音高和音量

包络编辑器让你可以画出音高曲线和音量变化，给歌声加上颤音、滑音，或者让某些词唱得更轻或更重。

🔧

选择运行设备

在设置里可以指定用哪张显卡跑合成，或者让程序自动选择。笔记本用户也可以手动切换到 CPU 模式省电。

🧪

有测试保障

160 多个自动化测试覆盖核心功能，每次修改代码都会跑一遍。虽然是个小项目，但质量上不想马虎。
