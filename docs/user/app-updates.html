Application Updates 应用更新

This page tracks notable user-facing changes to the SXSEditor application. For the full commit history, see the GitHub commit log. Application version numbers are auto-incremented by GitHub CI; the entries below are grouped by the order in which features landed on master.

本页追踪 SXSEditor 应用面向用户的重大变更。完整提交历史请查看 GitHub 提交日志。应用版本号由 GitHub CI 自动递增；下方条目按合入 master 的先后顺序分组。

ℹ️

Looking for model / inference changes? See Model Updates.

查找模型 / 推理相关变更？请见 模型更新。

Editor & Piano Roll 编辑器与钢琴卷帘

  • Fragment selection & deletion — fragments on the timeline can be selected with a click; press Delete or use the right-click context menu to remove them.片段选择与删除——时间线上的片段可点击选中；按 Delete 或右键菜单可删除。
  • Multi-note drag fix — resolved overlap and horizontal-stuck issues when dragging multiple notes at once.多音符拖动修复——修复了同时拖动多个音符时的重叠与水平卡顿问题。
  • Pitch smoothing slider — fixed the brush Smoothing slider having no effect; pitch curves now respect the slider value.音高平滑滑块——修复了画笔 Smoothing 滑块无效的问题；音高曲线现在会按滑块值平滑。
  • Right-click smoothness control — right-click a pitch anchor point to tune its smoothing strength individually.右键平滑度控制——右键点击音高锚点可单独调整其平滑强度。
  • Pitch curve auto-fit — the pitch curve is now fitted to the MIDI pitch only at note start/end, not across the whole note duration, preserving vibrato inside long notes.音高曲线自动拟合——音高曲线只在音符首尾拟合 MIDI 音高，而非整个音符时长，保留长音符内的颤音。
  • Lyric inline edit refresh — fixed lyrics entered inline not refreshing the note display until the next click.歌词内联编辑刷新——修复了内联输入的歌词在下次点击前不刷新音符显示的问题。
  • F1 shortcuts overlay — pressing F1 inside the Fragment Editor opens an in-app overlay listing all keyboard shortcuts.F1 快捷键面板——在片段编辑器中按 F1 可打开应用内快捷键面板。

Singer Creator 歌手创建器

  • File menu — the Singer Creator window now has a File menu with Save / Save As / Close actions.文件菜单——歌手创建器窗口新增文件菜单，提供 Save / Save As / Close 操作。
  • Save button in toolbar — a dedicated Save button is now available in the Singer Creator toolbar.工具栏保存按钮——歌手创建器工具栏新增专用 Save 按钮。
  • Preview playhead sync — the Singer Creator preview playhead is now synchronized with audible audio playback, fixing drift between visual and audio position.预览游标同步——歌手创建器预览游标现在与可听音频播放同步，修复了视觉与音频位置漂移。

UI & Theming 界面与主题

  • Bilingual documentation — the official website now ships bilingual EN / 中文 docs with automatic language switching. Older wiki markdown is superseded by the new HTML documentation tree.双语文档——官网现提供 EN / 中文 双语文档，支持自动语言切换。旧的 wiki markdown 已被新的 HTML 文档树取代。
  • ACG default theme — comprehensive UI optimization with the ACG theme as the new default.ACG 默认主题——全面 UI 优化，ACG 主题成为新的默认主题。
  • Window popup animations — windows now open with a popup animation; the timeline scroll direction was swapped to match user expectations.窗口弹出动效——窗口打开时增加弹出动效；时间线滚动方向已调整以符合用户预期。
  • Animated custom checkboxes — native checkboxes are replaced with animated custom checkboxes across settings dialogs.动画自定义复选框——设置对话框中的原生复选框已替换为带动画的自定义复选框。
  • Out-of-range MIDI pitch warning — notes outside the model's training pitch range (Japanese [48, 84], base [28, 88]) are visually marked with a gray fill, exclamation mark, and language-specific hover tooltip.超范围 MIDI 音高警告——超出模型训练音域的音符（日语 [48, 84]，基础模型 [28, 88]）会以灰色填充、感叹号及按语言显示的悬浮提示标记。

Playback & Audio Output 播放与音频输出

  • Per-fragment synthesis on main page — the main page now synthesizes per-fragment reusing the Fragment Editor logic, fixing audio mismatch between the two views.主页按片段合成——主页现在复用片段编辑器逻辑按片段合成，修复了两个视图间的音频不匹配。
  • VRAM-reference vocoder chunk sizing — a VRAM reference table is now used to pick a vocoder chunk size appropriate for the detected GPU.基于显存的 vocoder 分片——使用显存参考表为检测到的 GPU 选择合适的 vocoder 分片大小。
  • Long-synthesis OOM guard — prevents VRAM OOM and silent empty-audio playback on long synthesis runs.长合成 OOM 保护——防止长时合成时显存 OOM 与静音空音频播放。
  • Sequential synthesis — the synthesize() path is serialized to prevent session-rebuild races when multiple play requests overlap.串行合成——synthesize() 路径已串行化，防止多个播放请求重叠时会话重建竞争。

Model Management 模型管理

  • Per-precision model version tracking — each precision (FP32 / FP16 / INT8 / INT8-NPU) now has its own version metadata; switching precisions no longer invalidates unrelated cache entries.按精度模型版本追踪——每种精度（FP32 / FP16 / INT8 / INT8-NPU）现在拥有独立的版本元数据；切换精度不再使无关缓存条目失效。
  • Export dialog with precision selection — a dedicated export dialog lets you pick precision and shows per-file progress.带精度选择的导出对话框——专用导出对话框可挑选精度并显示每个文件的进度。
  • SiFiGAN precision selector — Settings now exposes a SiFiGAN precision selector (FP32 default, FP16 for low-resource).SiFiGAN 精度选择器——设置中新增 SiFiGAN 精度选择器（默认 FP32，低资源可选 FP16）。
  • FP8 precision removed — FP8 precision support was removed (the ONNX Runtime DirectML EP is not compatible with FP8).移除 FP8 精度——移除了 FP8 精度支持（ONNX Runtime DirectML EP 与 FP8 不兼容）。

Settings & Stability 设置与稳定性

  • Inference progress display & re-entrancy guard — synthesis progress is surfaced in the UI, with a re-entrancy guard preventing overlapping synthesis requests.推理进度显示与重入保护——合成进度在 UI 中显示，并加重入保护防止合成请求重叠。
  • ORTWEB / ORTNODE inference provider selection — Settings exposes an inference provider selector with WebNN GPU support.ORTWEB / ORTNODE 推理提供者选择——设置中新增推理提供者选择器，支持 WebNN GPU。
  • Optional DML VRAM release — releasing the DML memory pool after synthesis is now settings-controllable (recreates heavy sessions to reclaim VRAM).可选 DML 显存释放——合成后释放 DML 内存池现可由设置控制（通过重建重会话回收显存）。
  • NP/NPU settings keys — npuDiffBatchSize and npuVocoderBatchSize are now exposed through the allowlist.NPU 设置键——npuDiffBatchSize 与 npuVocoderBatchSize 已通过设置白名单暴露。
  • Process-exit timer unref — the ORT debug flush timer is now unreferenced so the process can exit cleanly.退出定时器 unref——ORT 调试刷新定时器已 unref，使进程能干净退出。
  • Cache key includes singerId — the synthesis cache key now includes singerId, so switching singers invalidates the cache correctly.缓存键包含 singerId——合成缓存键现在包含 singerId，切换歌手时缓存会正确失效。
  • phone_set.json fallback paths — added fallback paths and debug logging for phone_set.json loading.phone_set.json 回退路径——为 phone_set.json 加载新增回退路径与调试日志。

Project & File Handling 项目与文件处理

  • Save As embeds singers — File → Save As can optionally embed singer files into the project file to make it self-contained.另存为可嵌入歌手——File → Save As 可选择将歌手文件嵌入项目文件，使其自包含。
  • Fragment sync from .sxsproj — fixed fragment MIDI edits not syncing to the main page when a project is loaded from a .sxsproj file.从 .sxsproj 同步片段——修复了从 .sxsproj 加载项目时片段 MIDI 编辑不同步到主页的问题。
  • Close-all fragment editors — a closeAllFragmentEditors API was added with a pending-fragment-data snapshot to prevent data loss on window teardown.关闭全部片段编辑器——新增 closeAllFragmentEditors API，并带 pending-fragment-data 快照，防止窗口关闭时数据丢失。
  • Packaged-build module fix — fixed missing modules in the packaged build.打包构建模块修复——修复了打包构建中缺失模块的问题。

Bugs Fixed 缺陷修复

  • Resolved DXGI_ERROR_DEVICE_REMOVED (0x887A0006) / GPU device hung errors by serializing vocoder chunk inference (the root cause was concurrent session.run() calls on the same DML InferenceSession, not an ONNX Runtime version issue).通过串行化 vocoder 分片推理修复了 DXGI_ERROR_DEVICE_REMOVED (0x887A0006) / GPU 设备挂起错误（根因是同一 DML InferenceSession 上并发 session.run()，与 ONNX Runtime 版本无关）。
  • Fixed console encoding mojibake, audioWorker.js path, and mojo WidgetHost errors caused by premature openDevTools.修复了由过早 openDevTools 导致的 控制台编码乱码、audioWorker.js 路径与 mojo WidgetHost 错误。
  • Fixed pitch curve only fit MIDI pitch at note start/end to preserve vibrato inside long notes.修复了 音高曲线只在音符首尾拟合 MIDI 音高，保留长音符内的颤音。
