关于这个项目

为什么做 SXSEditor

缘起

做这个项目其实挺简单的——就是想写歌，但不会唱歌，也不想花钱请歌手。 市面上已有的歌声合成软件要么太贵，要么太复杂，要么不开源。 所以干脆自己做一个。

SXSEditor 把钢琴卷帘编辑器和神经网络歌声合成打包成一个桌面应用。 你不需要懂深度学习，不需要配环境，下载解压就能用。 所有的推理都在本地完成，你的歌、你的数据，完全属于你自己。

技术栈

这个项目用到了不少开源工具，感谢这些社区：

Vanilla JavaScript HTML5 Canvas Wavesurfer.js Electron Electron Forge Webpack ONNX Runtime Node SoulX-Singer DirectML RMVPE TensorFlow.js Mocha + Chai

项目结构

代码组织得还算清晰，主要分这几块：

  • src/main.js — Electron 主进程，管窗口和进程通信
  • src/renderer.js — 渲染进程，UI 交互和调用主进程 API
  • src/editor/ — 编辑器核心：轨道、钢琴卷帘、包络
  • src/inference/ — ONNX 推理：SVS、音高检测、MIDI 解析
  • src/audio/ — WAV 编码和音频工具
  • onnx_models/ — SoulX-Singer 的 ONNX 模型文件
  • test/ — 自动化测试，160 多个用例

音频规格

目前模型支持的参数：

  • 采样率：24000 Hz
  • Hop Size：480（20 ms）
  • FFT Size：1920
  • Window Size：1920
  • Mel 频带数：128
  • F0 范围：C1 ~ B6（32.7 Hz ~ 1975.5 Hz）
