关于项目

SXSEditor 的故事与技术

项目概述

SXSEditor 是一款开源的桌面歌声合成（Singing Voice Synthesis, SVS）与编辑应用。 它将可视化的钢琴卷帘编辑器与基于 SoulX-Singer 声学模型的神经网络 SVS 流水线相结合， 让你能够在一个集成化的桌面工作台中完成从作曲到合成的完整创作流程。

项目完全通过 ONNX Runtime 进行推理，支持 DirectML 加速，可在 NVIDIA、AMD 和 Intel 独立显卡上高效运行，同时兼容 CPU 回退方案。

技术栈

Vanilla JavaScript HTML5 Canvas Wavesurfer.js Electron Electron Forge Webpack ONNX Runtime Node SoulX-Singer DirectML RMVPE TensorFlow.js Mocha + Chai

项目结构

SXSEditor 采用清晰的分层架构设计：

  • src/main.js — Electron 主进程入口，窗口管理与 IPC 通信
  • src/renderer.js — 渲染进程逻辑，UI 交互与主进程 API 调用
  • src/editor/ — 轨道管理器、钢琴卷帘、包络编辑等核心编辑器组件
  • src/inference/ — ONNX 推理流水线（SVS、RMVPE 音高检测、Basic Pitch）
  • src/audio/ — WAV 编码器与音频工具函数
  • onnx_models/ — SoulX-Singer ONNX 模型文件
  • test/ — 完整的自动化测试套件（160+ 测试用例）

音频规格

  • 采样率：24000 Hz
  • Hop Size：480（20 ms）
  • FFT Size：1920
  • Window Size：1920
  • Mel 频带数：128
  • F0 范围：C1 ~ B6（32.7 Hz ~ 1975.5 Hz）
