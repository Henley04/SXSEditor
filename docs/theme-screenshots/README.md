# 主题截图 (Theme Screenshots)

此目录包含 4 套内置主题的 UI 截图，用于视觉回归对比。
This directory contains UI screenshots of the 4 built-in themes for visual regression comparison.

截图说明 / Screenshot notes:
- `dark-aurora.png` - Aurora 暗色（默认）
- `light-paper.png` - Paper 亮色
- `midnight-amber.png` - Midnight 琥珀
- `contrast-onyx.png` - Onyx 高对比

截图可在 `npm start` 启动后，手动切换主题并使用系统截图工具保存。
Screenshots can be captured manually after `npm start` — switch the theme in Settings and use any system screenshot tool to save the image.
