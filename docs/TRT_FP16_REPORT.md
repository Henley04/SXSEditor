## Setup
- Source: `SoulX-Singer/soulxsinger` PyTorch `model.pt` + `soulxsinger.yaml`
- FP32 base: `onnx_models/trt_fp16_fp32/` (isolated, not overwriting `onnx_models/`)
- Final TRT FP16: `onnx_models/trt_fp16/` (13 models: 9 main + 4 JP)
- Calibration: `eval_data/Soul-AILab/SoulX-Singer-Eval-Dataset` → `calibrate/data/trt_fp16/calib_data.npz` (50 mels, mel mean -4.92 std 2.85)
- Quantization: `Olive OnnxFloatToFloat16(op_block_list=[Softmax,LayerNorm,Div,Clip,...], keep_io_types=True)` + `OnnxQuantizationPreprocess` + `Peephole` + optional `OrtMixedPrecision` (calib)
- EP: `NvTensorRTRTXExecutionProvider` (MSIX 2.30.49.0) via `WinML`, fallback `OpenVINO`/`DML`
- HW: NVIDIA GeForce RTX 5060 Laptop GPU 8GB, Win11 24H2 26220, ORT 1.27
- Compatibility: filenames identical to `fp16/`; `xcopy trt_fp16\*.onnx fp16\ /Y` + `npm start` → `preflow/diff_step/vocoder [winml:NvTensor]`
