Quick Start

Get up and running with Nexus SDK in under 5 minutes.

1. Installation

Install via your preferred package manager:

terminal 
npm install @nexus/sdkyarn add @nexus/sdkpnpm add @nexus/sdk

2. Initialize Client

app.js 
import { NexusClient } from '@nexus/sdk';

const nexus = new NexusClient({
  apiKey: process.env.NEXUS_API_KEY,
  region: 'us-east-1',
  timeout: 5000,
});

// Ready to use!
const user = await nexus.users.get('user_123');
console.log(user);

3. Run Your First Query

query.py 
from nexus import NexusClient

client = NexusClient(api_key="your_key")

# Fetch documents with filtering
results = client.documents.query(
    collection="articles",
    filter={"status": "published"},
    limit=10,
    sort={"created_at": "desc"}
)

for doc in results:
    print(doc.title)

API Reference

Complete list of available REST endpoints and their parameters.

Method Endpoint Description
GET /v1/users/:id Retrieve a user by ID
POST /v1/users Create a new user account
PUT /v1/users/:id Update user information
DEL /v1/users/:id Permanently delete a user
GET /v1/documents List all documents in a collection
POST /v1/documents/query Execute a complex document query
03

Configuration

Customize Nexus SDK behavior with these configuration options.

apiKey Required
string

Your unique API key for authentication. Generate one in the dashboard.

region
string

Target deployment region. Defaults to the nearest edge location.

timeout
number

Request timeout in milliseconds. Default is 30000 (30 seconds).

retryAttempts
number

Number of automatic retry attempts on transient failures.
